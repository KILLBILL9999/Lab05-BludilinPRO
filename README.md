## ПР5. Ответы на контрольные вопросы

1. **Разница между while и do-while.** В while условие проверяется перед выполнением тела, поэтому тело может не выполниться ни разу. В do-while условие проверяется после тела, поэтому оно выполняется минимум один раз.

2. **Пример, где нужен do-while.** Меню программы или запрос ввода: их нужно показать хотя бы раз, до того как появится значение для проверки условия (например, menuChoice в меню).

3. **Забыли изменить переменную в условии while.** Условие всегда остаётся истинным, цикл никогда не завершается, программа зависает. Такая ситуация называется бесконечным циклом.

4. **Три части for.** Инициализация (int i = 1), условие (i <= 5), шаг (i++). На первой итерации: сначала инициализация (один раз), затем проверка условия, затем тело цикла; шаг выполняется только после тела. For предпочитают while, потому что все три части собраны в одной строке и сложнее забыть изменить счётчик (главная причина бесконечного цикла).

5. **foreach и for.** В foreach нет прямого доступа к индексу элемента, он просто перебирает элементы. В for есть счётчик-индекс (например, sentence[i]), поэтому можно узнать позицию элемента.

6. **break и continue.** break полностью прекращает выполнение цикла. continue пропускает только остаток тела текущей итерации и переходит к следующей.

7. **Шаг i++ при continue в for.** Да, шаг выполнится: после continue управление идёт к шагу, а затем к проверке условия. Иначе получился бы бесконечный цикл.

8. **break во внутреннем цикле.** Внешний цикл не остановится: break прерывает только тот цикл, в котором находится. В примере из Шага 12 при col == 3 внутренний цикл завершается, а строка «Внешняя итерация» всё равно выводится все 3 раза (для row = 1, 2, 3).
